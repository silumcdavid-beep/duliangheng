# 度量衡 · 单位换算器

高级简约风格的计量与单位换算工具，单文件、零依赖、完全离线可用。

## 功能

- **12 类单位**：长度、重量、面积、体积、温度、时间、速度、数据存储、压力、功率、能量、角度（约 90 个单位）
- 输入即实时换算，支持大数字与科学计数法
- 一键互换单位、复制结果
- 全量换算表：点击任意行设为目标单位，悬停复制
- 深色 / 浅色主题，自动记忆偏好
- 所有状态 localStorage 持久化，刷新不丢失

## 使用

直接打开 [在线地址](https://silumcdavid-beep.github.io/duliangheng/) 即可，或下载 `index.html` 本地双击打开（完全离线）。

## 数据基准

所有换算基于国际单位制（SI）定义；温度支持负数；数据存储按 1024 进制；月按 30 天、年按 365 天计。
